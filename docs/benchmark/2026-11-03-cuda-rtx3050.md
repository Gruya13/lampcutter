# SAM 2 benchmark — CUDA, RTX 3050 Laptop (4 GB)

**Datum:** 2026-11-03. **Specifikacija:** 11.1, 11.2, 13.2, 13.4.
**Uređaj:** NVIDIA GeForce RTX 3050 Laptop GPU, 4096 MiB VRAM (3,73 GiB po torch-u).

## Okruženje

| | |
|---|---|
| platforma | Linux x86_64 (Omarchy), 16 jezgara, 15 GB RAM |
| GPU drajver | NVIDIA 615.78.08 (Open Kernel Module), CUDA UMD 13.4 |
| Python / torch | 3.12.16 / 2.14.1+cu130 |
| SAM 2 | `facebookresearch/sam2 @ 2b90b9f5` (isti pin kao CPU benchmark) |
| checkpointi | SAM 2.1 tiny/small/base_plus/large, SHA256 u `models/manifest.json` |
| ulaz | ista 3 sintetička mockupa kao u CPU benchmarku |
| VRAM pre merenja | Voxtype (diktacija) privremeno zaustavljen → 2 MiB/4096 MiB slobodno |

> Voxtype je posle benchmarka **vraćen u rad** (provereno: servis aktivan,
> 1630 MiB VRAM, isti servis pre i posle).

|---|---|---|---|---|---|

## Poređenje CPU vs CUDA

| metrika | CPU (16 jezgara) | CUDA (RTX 3050) | ubrzanje |
|---|---|---|---|
| `set_image` (small) | 2.54 s | 0.03 s | ~85× |
| `predict` (base_plus) | 0.08 s | 0.11 s | ~1× (dekoder je sitan) |
| VRAM/RAM za `large` | 2163 MB RAM | 1451 MB VRAM | — |

Enkoder je ono što GPU ubrzava; `predict` je i na CPU već brz.

Ulaz: `tests/data/srce.png`, tačka (600, 800), visina 200 mm.

| varijanta | ukupno (prvi run u procesu) | SVG platno |
|---|---|---|
| small | 4.62 s | 205.51 × 200.00 mm + margine |

Prvi run uključuje CUDA inicijalizaciju i učitavanje modela. U GUI-ju se model
učitava jednom pri pokretanju (spec 12.2), pa je obrada po slici ~1 s —
**cilj „< 3 s na GPU" iz spec 13.4 je ispunjen sa marginom.**

## Zaključci i nalazi za spec 11.1

1. **CUDA je 70–85× brži od CPU za enkoder.** GPU cilj iz spec 13.4 je ispunjen.
2. **`large` staje u 4 GB VRAM** (1451 MB), suprotno pretpostavci iz spec 11.1
   („`large` isključen ispod ~8 GB"). Preporuka: u Fazi 0b izmeriti realno
   opterećenje sa interaktivnim radom (više `predict`-a, veće slike) pre nego što
   se podrazumevana vrednost promeni.
3. **Koegzistencija sa diktacijom je tesna, ali moguća:** Voxtype drži 1630 MB,
   SAM 2 `large` još 1451 MB → 3,1 GB od 4 GB. End-to-end sa `large` je prošao i sa
   aktivnim Voxtype-om. Ipak, za siguran rad preporuka: kad je diktacija aktivna
   koristiti `small`/`base_plus`; `large` čuvati za sesije bez diktacije.
4. **VRAM nije usko grlo za tiny/small/base_plus** (≤ 807 MB) — te varijante mogu
   da rade paralelno sa diktacijom bez problema.
5. Kvalitet maske je identičan CPU izlazu; odluka o podrazumevanoj varijanti se
   donosi na osnovu brzine i memorije, ne kvaliteta na ovim uzorcima.

## Reprodukcija

```bash
# CUDA wheel (draver CUDA 13.x; za CUDA 12 drajvere koristi cu128 index ako postoji wheel)
uv pip install --reinstall torch==2.14.1 torchvision==0.29.1 --index-url https://download.pytorch.org/whl/cu130
uv pip install setuptools wheel hydra-core iopath tqdm
uv pip install --no-build-isolation "sam-2 @ git+https://github.com/facebookresearch/sam2.git@2b90b9f5ceec907a1c18123530e92e794ad901a4"

# Voxtype (diktacija) drži VRAM — za merenje ga privremeno zaustavi:
systemctl --user stop voxtype
uv run --no-sync python scripts/benchmark.py --images tests/data --variants tiny,small,base_plus,large \
    --device cuda --reference-mm srce=200,figura8=220,ploca=150 --out benchmark_report/gpu
systemctl --user start voxtype   # obavezno vratiti
```

GPU nije vidljiv unutar DSH sandboxa (`/dev/nvidia*`), pa se benchmark na ovoj
mašini pokreće sa `--danger-full-access` ekvivalentom.
